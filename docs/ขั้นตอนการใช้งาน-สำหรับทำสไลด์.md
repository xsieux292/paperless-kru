# KruAssist — ขั้นตอนการใช้งาน (สำหรับทำสไลด์)

เอกสารนี้เขียนให้ก๊อปไปวางในสไลด์ได้เลย แต่ละหัวข้อ = 1 สไลด์
ทุก flow ใช้ได้จริงทั้งบน **เว็บ** และ **LINE OA** เพราะใช้ API layer และตรรกะชุดเดียวกัน

> **หมายเหตุตอนสาธิต:** prototype ใช้ข้อมูลจำลองที่เก็บในหน่วยความจำของแต่ละหน้า
> ถ้าสลับไปมาระหว่าง `/` กับ `/line-demo.html` ข้อมูลจะเริ่มใหม่จากชุดตั้งต้นเดียวกัน (ไม่ใช่บั๊ก)
> เมื่อต่อ backend จริงแล้วทั้งสองฝั่งจะเห็นข้อมูลเดียวกันทันที

- ระบบเว็บ: `npm run dev` → http://localhost:5173
- Prototype LINE OA: http://localhost:5173/line-demo.html
  (หรือไฟล์เดียวจาก `npm run build:prototype` เปิดได้โดยไม่ต้องมีเซิร์ฟเวอร์)

# Flow 2 — ส่งเอกสารให้ AI ทำแทน

## สไลด์ 11 — ขั้นที่ 1: เลือกว่าจะให้ AI ช่วยอะไร

| บริการ | ใช้ตอนไหน |
| --- | --- |
| **เติมข้อมูลลงแบบฟอร์ม** | มีแบบฟอร์มเปล่า อยากให้ AI กรอกให้ครบ |
| **แปลงรูปถ่ายเป็นเอกสาร** | ถ่ายรูปกระดาษ/กระดาน อยากได้เป็นไฟล์พิมพ์ |
| **ทำบัญชีจากใบเสร็จ** | มีใบเสร็จหลายใบ อยากได้ตารางสรุป |

**จุดขาย:** การ์ดที่เลือกอยู่เป็นสีเขียว + เครื่องหมายถูก + ข้อความ "เลือกอยู่" — ไม่พึ่งสีอย่างเดียว คนตาบอดสีก็ใช้ได้

## สไลด์ 11.5 — AI เดาให้ตั้งแต่แนบไฟล์ ⭐

พอครูแนบไฟล์ปุ๊บ **AI อ่านแล้วตั้งค่าให้เองทันที** ครูไม่ต้องเลือกอะไรเลย

| AI ตั้งให้ | ตัวอย่าง |
| --- | --- |
| บริการ | เห็นชื่อไฟล์ว่า "ใบเสร็จ" → เลือกโหมดทำบัญชีให้ |
| โครงการ | เดาจากโครงการที่ใช้ล่าสุด *(ขึ้น ⚠ AI ไม่แน่ใจ ให้ครูตรวจ)* |
| ประเภทใบเสร็จ | ค่าวัสดุ/อุปกรณ์ |
| ร้านค้า / ยอดเงิน / วันที่ | อ่านจากใบเสร็จให้ |
| **VAT** | **คำนวณให้เอง** — "ยอดนี้รวม VAT 7% แล้ว คิดเป็นภาษี 81.78 บาท" |

**จุดขาย:** จากเดิมครูต้องแตะเลือกเอง 3 ครั้ง (บริการ + โครงการ + ประเภท)
ตอนนี้เหลือ **0 ครั้ง** — แค่ดูว่าถูกไหม ถ้าไม่ถูกค่อยแก้เฉพาะจุด
และมีปุ่ม **"เลือกเองทั้งหมด"** เผื่อครูอยากตั้งเอง

## สไลด์ 12 — ขั้นที่ 2: เลือกแบบฟอร์มที่เคยส่งไว้ ⭐

| | |
| --- | --- |
| **ครูเห็น** | รายการแบบฟอร์มที่เคยใช้ **เรียงตามที่ใช้บ่อยที่สุด** พร้อมบอกว่าใช้ไปกี่ครั้ง ล่าสุดเมื่อไร |
| **ครูทำ** | แตะเลือก 1 แบบฟอร์ม — **ไม่ต้องหาไฟล์เดิมในเครื่องอีก** |
| **จุดขาย** | โรงเรียนใช้แบบฟอร์มชุดเดิมทั้งปี การให้ครูไปหาไฟล์เดิมทุกครั้งคือ**จุดที่ครูติดบ่อยที่สุด** ระบบจึงจำให้ |

> โหมดทำบัญชี ขั้นนี้จะให้เลือก **โครงการ + ประเภทใบเสร็จ** แทน เพื่อให้รายงานแยกกัน

## สไลด์ 13 — ขั้นที่ 3: ตรวจทานก่อนส่ง

| | |
| --- | --- |
| **ครูเห็น** | สรุปครบในหน้าเดียว: บริการ / แบบฟอร์ม / โครงการ / ไฟล์แนบ / คำสั่งเพิ่มเติม |
| **ครูทำ** | (ถ้าอยาก) แตะปุ่มคำสั่งสำเร็จรูป เช่น "สรุปเป็นยอดรวมรายเดือนให้ด้วย" → กดปุ่มเขียว |

## สไลด์ 14 — ผลลัพธ์: AI ทำงานให้ ครูไปพักได้

## สไลด์ 17 — ขั้นที่ 2: AI ร่างให้ครบทั้งใบ แล้วครูแค่ตรวจ ⭐⭐

จากประโยคเดียว AI เดาให้ครบ **6 อย่าง**:

| ช่อง | AI เดามาจาก |
| --- | --- |
| ประเภท (เบิก/ยืม) | คำว่า "ซื้อ" → เบิกงบซื้อของ |
| เรื่อง | เรียบเรียงเป็นภาษาราชการ → *"ขอจัดซื้อวัสดุอุปกรณ์สำหรับจัดกิจกรรมวันวิทยาศาสตร์"* |
| โครงการ | จับคำว่า "วิทยาศาสตร์" → โครงการวันวิทยาศาสตร์ (+ โชว์งบคงเหลือ) |
| วันที่ต้องใช้ | คำว่า "สัปดาห์หน้า" → คำนวณวันที่ให้ |
| ผู้อนุมัติ | **ตามวงเงินอัตโนมัติ** — เกิน 5,000 บาทส่ง ผอ. ไม่เกินส่งรอง ผอ. |
| รายการของ | เสนอ 4 รายการพร้อมราคาและเหตุผล |

**สิ่งที่ทำให้ครูเชื่อใจ AI ได้**
- ป้าย **"5/5 ชัดเจน"** บอกว่า AI มั่นใจกี่ช่อง
- ช่องที่มั่นใจขึ้น **✓ AI มั่นใจ** สีเขียว — ครูข้ามได้เลย
- ช่องที่ไม่มั่นใจขึ้น **⚠ AI ไม่แน่ใจ** สีส้ม **พร้อมบอกเหตุผล** เช่น *"เดาจากโครงการที่ใช้ล่าสุด — กรุณาตรวจว่าถูกโครงการไหม"*
- **ทุกช่องแก้ได้ทันที** ไม่ต้องกดปุ่ม "แก้ไข" ก่อน

## สไลด์ 18 — ขั้นที่ 3: กดปุ่มเดียวจบ

| | |
| --- | --- |
| **ครูทำ** | กด **"ถูกต้องแล้ว — ส่งให้เซ็นอนุมัติ"** |
| **ได้อะไร** | เลขที่เอกสารจริง เช่น `บก.01-2569-0842` · เข้ารายการ "ใบเบิกของฉัน" สถานะรออนุมัติ |

- ทุกหน้ามี **empty state** เช่น *"ตอนนี้ไม่มีงานค้างเลยค่ะ 🎉"* ไม่ปล่อยจอโล่ง

## สไลด์ 22 — สิ่งที่ทำให้ต่างจากระบบอื่น

1. **OCR + OTP + Auto Portfolio ครบในที่เดียว** — คู่แข่งมักมีแค่อย่างใดอย่างหนึ่ง
2. **อยู่บน LINE** — ครูไม่ต้องเรียนรู้แอปใหม่ ไม่ต้องจำรหัสผ่านเพิ่ม
3. **AI เดาให้ก่อนเสมอ ครูแค่ตรวจ** — ไม่ใช่ให้ครูกรอกจากหน้าว่าง
   ทุกค่าที่ AI เดาบอกด้วยว่า**มั่นใจแค่ไหนและเดามาจากอะไร** ครูจึงตัดสินใจได้ว่าจะเชื่อไหม
4. **ออกแบบมาเพื่อครูที่ไม่ถนัดเทคโนโลยีโดยเฉพาะ** — ปรับขนาดตัวอักษรได้ ปุ่มใหญ่ ข้อความไม่มีศัพท์เทคนิค
5. **เว็บกับ LINE เป็นระบบเดียวกัน** — ใช้ API layer และตรรกะชุดเดียวกัน ครูจะเริ่มจากมือถือหรือคอมก็ได้
