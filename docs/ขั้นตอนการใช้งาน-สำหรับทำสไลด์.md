# KruAssist — ขั้นตอนการใช้งาน (สำหรับทำสไลด์)

เอกสารนี้เขียนให้ก๊อปไปวางในสไลด์ได้เลย แต่ละหัวข้อ = 1 สไลด์
ทุก flow ใช้ได้จริงทั้งบน **เว็บ** และ **LINE OA** เพราะใช้ API layer และตรรกะชุดเดียวกัน

> **หมายเหตุตอนสาธิต:** prototype ใช้ข้อมูลจำลองที่เก็บในหน่วยความจำของแต่ละหน้า
> ถ้าสลับไปมาระหว่าง `/` กับ `/line-demo.html` ข้อมูลจะเริ่มใหม่จากชุดตั้งต้นเดียวกัน (ไม่ใช่บั๊ก)
> เมื่อต่อ backend จริงแล้วทั้งสองฝั่งจะเห็นข้อมูลเดียวกันทันที

- ระบบเว็บ: `npm run dev` → http://localhost:5173
- Prototype LINE OA: http://localhost:5173/line-demo.html
  (หรือไฟล์เดียวจาก `npm run build:prototype` เปิดได้โดยไม่ต้องมีเซิร์ฟเวอร์)

## สไลด์ 1 — ปัญหาที่แก้

**ครูใช้เวลากับงานเอกสารมากกว่าการสอน**

| งานที่กินเวลา | เดิมทำยังไง | หลังมี KruAssist |
| --- | --- | --- |
| ลงบัญชีใบเสร็จ | พิมพ์ตัวเลขเข้า Excel ทีละใบ | ถ่ายรูป → AI อ่านให้ → ตรวจ 1 ช่อง |
| กรอกแบบฟอร์มราชการ | เปิดไฟล์เก่า ก๊อปวาง แก้ทีละช่อง | เลือกแบบฟอร์มที่เคยใช้ → AI กรอกให้ |
| เบิกงบ / ยืมพัสดุ | เขียนใบเบิก เดินเอกสารหาคนเซ็น | กรอก 3 ขั้น → ระบบส่งให้เซ็นเอง |
| ทำแฟ้ม ว.PA | รวบรวมย้อนหลังตอนใกล้ส่ง | ระบบเก็บให้ตลอดปี กด Export |

> **เป้าหมายการออกแบบ:** ครูเปิดหน้าจอมา ภายใน 3 วินาที ต้องรู้เองว่าต้องกดตรงไหน

# Flow 1 — ถ่ายใบเสร็จ → ลงบัญชี → เซ็นอนุมัติ
### ⭐ Flow สำคัญที่สุด · จบใน 3 แตะ / 90 วินาที

## สไลด์ 4 — ขั้นที่ 1: แตะ "ถ่ายใบเสร็จ"

| | |
| --- | --- |
| **ครูเห็น** | แชท KruAssist พร้อม Rich Menu 6 ช่องอยู่ล่างจอ |
| **ครูทำ** | แตะช่องสีเขียวทึบมุมซ้ายบน |
| **จุดขาย** | ไม่ต้องเปิดแอปใหม่ ไม่ต้องล็อกอิน แตะเดียวถึงงานเลย |

## สไลด์ 5 — ขั้นที่ 2: กล้องเปิดทันที

| | |
| --- | --- |
| **ครูเห็น** | กล้องเต็มจอ + กรอบไกด์ "วางใบเสร็จให้อยู่ในกรอบนี้" |
| **ครูทำ** | วางใบเสร็จในกรอบ แล้วแตะปุ่มชัตเตอร์ |
| **จุดขาย** | ตัดหน้าคั่นทิ้งหมด — ครูมีเวลาว่างครั้งละ 2–5 นาทีเท่านั้น กรอบไกด์ช่วยให้ OCR อ่านแม่นขึ้นตั้งแต่ต้นทาง |

## สไลด์ 6 — ขั้นที่ 3: AI อ่านให้แล้ว ครูแค่ตรวจ ⭐

| | |
| --- | --- |
| **ครูเห็น** | ช่องที่ AI มั่นใจ = **เทา อ่านอย่างเดียว** มีแม่กุญแจ<br>ช่องที่ AI ไม่มั่นใจ = **ส้ม ขอบหนา** พร้อมแถบ "แก้แค่ 1 ช่องพอค่ะ" |
| **ครูทำ** | แก้เฉพาะช่องส้ม (ยอดเงิน) แล้วกดปุ่มเขียวล่างจอ |
| **จุดขาย** | **นี่คือ pattern หลักของทั้งระบบ — AI ทำก่อน ครูแค่ตรวจ**<br>บอกจำนวนตรง ๆ ว่าเหลือแก้กี่ช่อง ครูรู้ทันทีว่างานเหลือแค่ไหน |

## สไลด์ 7 — ขั้นที่ 4: เลือกโครงการและหมวดค่าใช้จ่าย

| | |
| --- | --- |
| **ครูเห็น** | การ์ดโครงการพร้อม **งบคงเหลือ** และเตือนสีส้มถ้าใช้เกิน 85% |
| **ครูทำ** | แตะโครงการ 1 อัน + เลือกประเภทใบเสร็จ (ค่าวัสดุ / ค่าอาหาร / ค่าเดินทาง …) |
| **จุดขาย** | ครูคนเดียวดูหลายโครงการ ถ้าไม่แยกตั้งแต่ตอนส่ง รายงานจะปนกันจนต้องมานั่งแยกทีหลัง — ระบบแยกให้ตั้งแต่ต้นทาง |

## สไลด์ 8 — ขั้นที่ 5: การ์ดสรุปเด้งเข้าแชท

| | |
| --- | --- |
| **ครูเห็น** | Flex Message สรุป: ร้านค้า / หมวดงบ / **ยอดเงินตัวใหญ่** + ปุ่ม "เซ็นอนุมัติด้วย OTP" |
| **ครูทำ** | ตรวจอีกรอบ แล้วแตะปุ่มในการ์ด |
| **จุดขาย** | สรุปกลับเข้าแชท = ครูมีหลักฐานเก็บในห้องแชทตัวเอง ย้อนดูได้ตลอดโดยไม่ต้องเปิดระบบ |

## สไลด์ 9 — ขั้นที่ 6: เซ็นด้วย OTP ⭐ จุดที่ครูกังวลที่สุด

| | |
| --- | --- |
| **ครูเห็น** | ไอคอนกุญแจ → กล่องสรุป (เซ็นให้ใคร เอกสารอะไร **ยอดเท่าไร**) → ข้อความเตือนใจ → ช่อง OTP 6 ช่อง → timer |
| **ครูทำ** | กรอกรหัส 6 หลัก แล้วแตะ "ยืนยันการเซ็น" |
| **จุดขาย** | ออกแบบให้ **"อุ่นใจ" ไม่ใช่ "รีบกด"**<br>ข้อความเตือนใช้**สีเทาเข้ม ไม่ใช่แดง** เพราะแดงทำให้รู้สึกว่ากำลังทำผิด ทั้งที่เป็นขั้นตอนปกติ |

## สไลด์ 10 — ขั้นที่ 7: การ์ดหลักฐานเข้าแชท

| | |
| --- | --- |
| **ครูเห็น** | ✓ เขียว + เลขที่เอกสาร + เวลาที่เซ็น + **"ขั้นตอนถัดไป: ส่งให้ ผอ. แล้ว รอผลภายใน 2 วันทำการ"** |
| **จุดขาย** | ไม่จบแค่ ✓ เขียว แต่**บอกต่อว่าเกิดอะไรขึ้น** ครูจึงรู้ว่าต้องรออะไร ไม่ต้องเดา |

# Flow 2 — ส่งเอกสารให้ AI ทำแทน

## สไลด์ 11 — ขั้นที่ 1: เลือกว่าจะให้ AI ช่วยอะไร

| บริการ | ใช้ตอนไหน |
| --- | --- |
| **เติมข้อมูลลงแบบฟอร์ม** | มีแบบฟอร์มเปล่า อยากให้ AI กรอกให้ครบ |
| **แปลงรูปถ่ายเป็นเอกสาร** | ถ่ายรูปกระดาษ/กระดาน อยากได้เป็นไฟล์พิมพ์ |
| **ทำบัญชีจากใบเสร็จ** | มีใบเสร็จหลายใบ อยากได้ตารางสรุป |

**จุดขาย:** การ์ดที่เลือกอยู่เป็นสีเขียว + เครื่องหมายถูก + ข้อความ "เลือกอยู่" — ไม่พึ่งสีอย่างเดียว คนตาบอดสีก็ใช้ได้

## สไลด์ 12 — ขั้นที่ 2: เลือกแบบฟอร์มที่เคยส่งไว้ ⭐

| | |
| --- | --- |
| **ครูเห็น** | รายการแบบฟอร์มที่เคยใช้ **เรียงตามที่ใช้บ่อยที่สุด** พร้อมบอกว่าใช้ไปกี่ครั้ง ล่าสุดเมื่อไร |
| **ครูทำ** | แตะเลือก 1 แบบฟอร์ม — **ไม่ต้องหาไฟล์เดิมในเครื่องอีก** |
| **จุดขาย** | โรงเรียนใช้แบบฟอร์มชุดเดิมทั้งปี การให้ครูไปหาไฟล์เดิมทุกครั้งคือ**จุดที่ครูติดบ่อยที่สุด** ระบบจึงจำให้ |

> โหมดทำบัญชี ขั้นนี้จะให้เลือก **โครงการ + ประเภทใบเสร็จ** แทน เพื่อให้รายงานแยกกัน

## สไลด์ 13 — ขั้นที่ 3: ตรวจทานก่อนส่ง

| | |
| --- | --- |
| **ครูเห็น** | สรุปครบในหน้าเดียว: บริการ / แบบฟอร์ม / โครงการ / ไฟล์แนบ / คำสั่งเพิ่มเติม |
| **ครูทำ** | (ถ้าอยาก) แตะปุ่มคำสั่งสำเร็จรูป เช่น "สรุปเป็นยอดรวมรายเดือนให้ด้วย" → กดปุ่มเขียว |
| **จุดขาย** | ส่งผิดโหมดหรือผิดไฟล์ = ต้องทำใหม่ทั้งรอบ หน้านี้กันไว้ก่อน<br>ปุ่มคำสั่งสำเร็จรูปช่วยครูที่**คิดคำสั่งไม่ออก** ซึ่งเป็นจุดที่คนมักข้ามไป |

## สไลด์ 14 — ผลลัพธ์: AI ทำงานให้ ครูไปพักได้

| | |
| --- | --- |
| **ครูเห็น** | ข้อความยืนยันในแชท + งานเข้าคิวในช่อง "งานของฉัน" |
| **จุดขาย** | บอกชัดว่า **"ปิดแชทไปพักได้เลย ระบบทำต่อให้เอง"** ครูไม่ต้องนั่งเฝ้าหน้าจอ |

# Flow 3 — เบิกงบ / ยืมพัสดุ

## สไลด์ 15 — ขั้นที่ 1: ข้อมูลคำขอ

| | |
| --- | --- |
| **ครูเห็น** | แถบ "ขั้นที่ 1 จาก 3" · เลือกเบิกงบ หรือ ยืมพัสดุ · เรื่อง · โครงการ (**เห็นงบคงเหลือ**) · วันที่ต้องใช้ |
| **จุดขาย** | เห็นงบคงเหลือตั้งแต่ตอนเลือก ไม่ต้องไปเปิดดูที่อื่น<br>มีแถบบอกขั้นตอนตลอด ครูไม่รู้สึกว่ากรอกไม่จบสักที |

## สไลด์ 16 — ขั้นที่ 2: "ให้ AI ช่วยคิดรายการอุปกรณ์" ⭐ จุดขายหลัก

| | |
| --- | --- |
| **ครูทำ** | พิมพ์สั้น ๆ เช่น *"จัดกิจกรรมวันวิทยาศาสตร์ มีฐานทดลอง 5 ฐาน"* |
| **AI ตอบ** | รายการ + จำนวน + **ราคาประมาณ** + **เหตุผลว่าทำไมถึงแนะนำ** เช่น<br>• บีกเกอร์แก้ว 250 ml — 10 ใบ × 85 บาท *(ใช้ประจำในการทดลองพื้นฐาน)*<br>• แว่นตานิรภัย — 20 อัน × 65 บาท *(จำเป็นเมื่อมีสารเคมี)* |
| **ครูทำ** | ระบบ**ติ๊กเลือกไว้ให้หมดแล้ว** ครูแค่เอาอันที่ไม่ต้องการออก |
| **จุดขาย** | ครูส่วนใหญ่ติดตรง **"ไม่รู้จะเบิกอะไรบ้าง"** — AI ตั้งต้นให้ แล้วครูแค่ตัดออก เร็วกว่าเริ่มจากศูนย์มาก |

## สไลด์ 17 — ขั้นที่ 3: ผู้อนุมัติ + ตรวจทาน

| | |
| --- | --- |
| **ครูเห็น** | รายชื่อผู้มีอำนาจเซ็น + สรุปทั้งใบ + **เตือนสีส้มถ้ายอดเกินงบคงเหลือ** |
| **ครูทำ** | เลือกคนเซ็น → กดส่ง |
| **จุดขาย** | เตือนเรื่องงบ**ก่อนส่ง** ดีกว่าให้ถูกตีกลับแล้วต้องทำใหม่ทั้งใบ<br>ระบบส่งให้ผู้อนุมัติเอง — **ครูไม่ต้องเดินเอกสาร** |

## สไลด์ 18 — ผลลัพธ์: ได้เลขที่เอกสารทันที

- ได้เลขที่จริง เช่น `บก.01-2569-0842` ใช้อ้างอิงกับเจ้าหน้าที่พัสดุได้เลย
- ใบเบิกเข้าไปอยู่ในรายการ **"ใบเบิกของฉัน"** สถานะ *รอผู้อนุมัติเซ็น*
- ถ้าถูกตีกลับ ระบบ**บอกเหตุผท**ไว้ให้แก้ตรงจุด เช่น *"ยอดเกินวงเงินที่เหลือของโครงการ"*

# Flow 4 — งานของฉัน (ติดตามงานทั้งหมด)

## สไลด์ 19 — ที่เดียวเห็นครบ

| แท็บ | เห็นอะไร |
| --- | --- |
| **งานที่ส่งให้ AI** | งานที่กำลังทำ (มีแถบความคืบหน้า + บอกเวลาที่เหลือ) และไฟล์ที่เสร็จแล้วพร้อมปุ่มดาวน์โหลด |
| **ใบเบิกของฉัน** | ใบเบิกทั้งหมด แยกสถานะ: รออนุมัติ / อนุมัติแล้ว / ถูกตีกลับ |

**จุดขาย**
- ความคืบหน้าเดินตามเวลาจริงและ**รีเฟรชเอง** ไม่ต้องกดรีเฟรช
- สถานะใช้ **สี + ไอคอน + ข้อความ** ครบทุกตัว
- ทุกหน้ามี **empty state** เช่น *"ตอนนี้ไม่มีงานค้างเลยค่ะ 🎉"* ไม่ปล่อยจอโล่ง

## สไลด์ 21 — หลักการออกแบบ 8 ข้อ ที่ใช้ทุกหน้าจอ

| # | หลักการ | เห็นได้จาก |
| --- | --- | --- |
| ① | หนึ่งจอ = หนึ่งงาน = **หนึ่งปุ่มทึบ** | ก่อนเลือกไฟล์ ปุ่มทึบคือ "ถ่ายรูป" พอมีไฟล์แล้วย้ายไปปุ่มส่ง |
| ② | ปุ่มหลัก**ติดล่างจอเสมอ สูง 56px** | ตำแหน่งเดิมทุกหน้า นิ้วโป้งเอื้อมถึง |
| ③ | ปุ่มเขียนเป็น **"กริยา + สิ่งของ"** | "ส่งใบเสร็จให้ AI ทำบัญชี" ไม่ใช่ "ตกลง" |
| ④ | **ไอคอนมีข้อความคู่เสมอ** | ทุกช่อง Rich Menu และปุ่มลบไฟล์ |
| ⑤ | **สีมีความหมายเดียว** | 🟢 เรียบร้อย · 🟠 ตรงนี้รอคุณอยู่ · 🔴 มีปัญหา · ⚪ อ่านอย่างเดียว |
| ⑥ | **AI ทำก่อน ครูแค่ตรวจ** | หน้าตรวจ OCR + AI ช่วยคิดรายการ + AI เขียนสรุป ว.PA |
| ⑦ | **ไม่มีทางตัน** | ทุกจอมีย้อนกลับ / เก็บเป็นร่าง / ถามเจ้าหน้าที่ |
| ⑧ | **ใช้ภาษาโรงเรียน** | "ใบเบิก" "เรียนฟรี 15 ปี" "ว.PA" — ไม่มี Submit / Sync / Dashboard |

## สไลด์ 22 — สิ่งที่ทำให้ต่างจากระบบอื่น

1. **OCR + OTP + Auto Portfolio ครบในที่เดียว** — คู่แข่งมักมีแค่อย่างใดอย่างหนึ่ง
2. **อยู่บน LINE** — ครูไม่ต้องเรียนรู้แอปใหม่ ไม่ต้องจำรหัสผ่านเพิ่ม
3. **AI ตั้งต้นให้เสมอ** ไม่ใช่ให้ครูกรอกจากศูนย์
4. **ออกแบบมาเพื่อครูที่ไม่ถนัดเทคโนโลยีโดยเฉพาะ** — ปรับขนาดตัวอักษรได้ ปุ่มใหญ่ ข้อความไม่มีศัพท์เทคนิค
5. **เว็บกับ LINE เป็นระบบเดียวกัน** — ใช้ API layer และตรรกะชุดเดียวกัน ครูจะเริ่มจากมือถือหรือคอมก็ได้

## สไลด์ 24 — ขั้นต่อไป

**Phase 1 (ทำแล้วใน prototype นี้)**
ถ่ายใบเสร็จ · ส่งเอกสารให้ AI · เบิกงบ/ยืมพัสดุ · เซ็น OTP · งานของฉัน · แฟ้ม ว.PA

**Phase 2**
Smart Syllabus (ปฏิทินการสอน) · AI Advisor แนะนำงานแข่ง/อบรม · ตั้งค่าแจ้งเตือน

**Phase 3 (ต้องเคลียร์ PDPA ก่อน)**
Student Insight — ต้อง anonymize ข้อมูลนักเรียนก่อนส่งให้ AI และขอความยินยอมจากโรงเรียน

**ความเสี่ยงที่ต้องเช็กก่อนใช้จริง**
- ผลทางกฎหมายของ e-Signature ตาม พ.ร.บ.ธุรกรรมทางอิเล็กทรอนิกส์
- แบบฟอร์มเบิกจ่ายของโรงเรียนยื่นแบบดิจิทัลได้จริงหรือไม่
- ความแม่นของ OCR กับใบเสร็จเขียนมือ
- โควตา push message ของแพ็กเกจ LINE OA
